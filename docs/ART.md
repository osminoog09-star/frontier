# 🎨 FRONTIER — Визуальный стайл-гайд

> Игрокам важна картинка. Визуал прокачиваем на КАЖДОМ этапе, а не в конце.

## Общий стиль
- Тёплая палитра Дикого Запада: песок, выжженная трава, охра, дерево, ночная синева.
- Читаемость важнее реализма: силуэты пешек/врагов/ресурсов мгновенно различимы.
- Лёгкая «нарисованность» (мягкие тени, объём), без жёсткого пиксель-арта, но опрятно.

## Сетка и камера
- Тайл = 24px. Карта 80×60. Зум 0.4×–2.8×.
- Камера: перетаскивание, колесо/кнопки/пинч, миникарта-переход.

## Палитра (базовая)
- Земля `#9c7b4e`, Трава `#6f9a4a`, Песок `#d9bd86`, Вода `#2f6ea8`, Скала `#7a7570`, Снег `#dfe6ef`.
- Акцент-золото `#e8c97e`, опасность `#c04444`, дружба/успех `#7ca84e`.
- UI: тёмный фон `#161616`/`#111`, рамки `#2a2a2a`/`#3a3320`.

## Террейн (Неделя 1: автотайлинг)
- Плавные переходы между биомами (трава↔песок↔земля) — краевые маски/градиенты.
- Береговая линия: светлая кромка у воды, лёгкая анимация бликов.
- Сезонный тинт: весна/лето/осень/зима (снег зимой).

## Спрайты пешек
- Ковбой: тело+жилет (цвет по id), шляпа, голова, ноги/руки с анимацией ходьбы.
- Состояния: работа (топор/кирка/молот), стрельба (револьвер), сон (лёжа), досуг, срыв.
- Враги: тёмная шляпа, бандана, оружие; босс крупнее с подписью.
- Над головой: имя, HP-бар (только при ранении), иконка состояния/мысли.

## Здания
- Узнаваемые силуэты: ферма с грядками, салун с крышей и окнами, кузня с горном (свечение),
  колодец, палатка-лагерь, клиника с крестом, вышка с флагом.
- Чертёж — синий пунктир + призрак иконки + полоса прогресса.
- Состояние: HP-бар при повреждении, свечение окон ночью.

## Эффекты и частицы (Неделя 1+)
- Пыль при рубке/добыче/стройке, щепки/осколки.
- Вспышка выстрела, трассер пули, попадание (брызги).
- Искры в кузне, дым из труб, рябь на воде, листва на ветру.
- Кровь на земле (затухает), надгробия.

## Освещение
- Плавный цикл день/ночь: рассвет/закат тёплый, ночь синяя.
- Тёплое свечение окон/костров ночью (additive).
- Погода затемняет (гроза/метель).

## UI
- Тёмная тема, моноширинный акцент, золотые заголовки.
- Панели: пешки (карточки с трейтами и шкалами), расписание (сетка часов), наука, лог.
- Тосты достижений, HUD цели с прогресс-баром, миникарта, кнопки зума/звука/экрана.
- Анимации: плавное появление панелей/тостов, ховер-подсветка.

## Анимация (приоритеты)
1. Ходьба пешек (есть) → 2. Рабочие действия → 3. Стрельба/бой → 4. Животные/лошади → 5. UI-переходы.
