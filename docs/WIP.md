# 🔒 WIP — текущая работа агентов (Codex / Claude / cloud)

Этот файл — «замок», чтобы два агента не делали одно и то же и не ломали работу друг другу.

## Как пользоваться (ОБЯЗАТЕЛЬНО)
1. **Перед началом среза** прочитай раздел «Сейчас в работе» ниже.
   - Если там уже есть задача со статусом `IN PROGRESS` от другого агента — **НЕ начинай её**. Возьми другую из «Очереди».
2. **Когда берёшь задачу** — впиши её в «Сейчас в работе» со статусом `IN PROGRESS`, своим именем и временем.
3. **Когда закончил и закоммитил** — убери задачу отсюда (или перенеси в `docs/CHANGELOG.md`).
4. **Если не успел доделать (закончились токены/время)** — оставь задачу здесь со статусом
   `PAUSED` и подробно опиши: что уже сделано, что осталось, какие файлы трогал. Другой агент тогда
   либо продолжит с этого места, либо НЕ начнёт с нуля.

Формат записи:
```
- [IN PROGRESS|PAUSED] <автор> <дата> — <название среза>
  - Сделано: ...
  - Осталось: ...
  - Затронутые файлы: ...
```
